# 悬赏厅完整卷 · 身份卡

> 版本 v1 · 2099-01-02 · gate 备料：角色画像 + 考题 + 身份×题矩阵

## 一、身份卡组

### 楼主（悬赏发起方）

- 要办成什么：把卡住的问题挂成悬赏，靠通知页跟进新回答，72 小时内点掉采纳拿到答案。
- 最怕什么：忘了看页面错过采纳窗口，或者悬赏被下架了没人告诉他原因。
- 懂多少：熟悉业务问题，平台操作停留在点按钮层面，不看帮助文档。
- 卡住了怎么办：先看消息通知页与悬赏详情的状态说明，再走工单通道，48 小时内有人应。

### 回答者（答题挣积分的工程师）

- 要办成什么：刷列表挑一单有把握的悬赏答掉，在通知页等到采纳与到账消息，月底积分兑调休。
- 最怕什么：答案被采纳了却不知道，或者到账积分和悬赏金额对不上。
- 懂多少：对技术领域在行，对悬赏规则只记得大概，依赖页内提示与通知角标。
- 卡住了怎么办：在通知页核对到账消息，再到悬赏详情核对采纳状态，异常走工单通道。

### 平台运营（内容治理值班）

- 要办成什么：巡查列表里的灌水与广告悬赏，24 小时内完成下架并留下原因。
- 最怕什么：误伤正常悬赏没有留痕，或者下架了楼主没收到通知引发投诉。
- 懂多少：熟悉社区治理规则与违规判例，不需要懂数据库操作，只走页面动作。
- 卡住了怎么办：先查下架原因与操作时间留痕，拿不准的悬赏挂起并找主管复核。

### 找茬者

- 发布表单填 0 或负数积分照样建单，冻结环节被绕过 → FR-01
- 标题只有一个字也能发布，列表出现无法辨识的悬赏 → FR-01
- 空内容回答直接提交成功，详情页出现空卡片 → FR-02
- 采纳划账出现双方积分同时减少的中间态 → FR-03
- 新回答或到账事件丢失，通知页少记录、角标数对不上 → FR-04
- 下架后冻结积分没有退回楼主账上 → FR-05
- 下架不填原因也能确认，治理动作无留痕 → FR-05
- 回答者能进我的悬赏看到楼主全部单据，权限没有收敛 → NFR-02
- 300 条种子数据下列表渲染拖到 3 秒以后 → NFR-01
