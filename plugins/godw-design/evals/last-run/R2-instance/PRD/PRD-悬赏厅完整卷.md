## 2 全局交互约定

- 角色切换在顶栏完成，登录态跨页保留；切换后页面入口与动作按角色收敛；
- 四页以悬赏列表为中心流转：列表进详情、我的悬赏、通知，其余页面回到列表；
- 时间类字段统一展示为发布时间、采纳截止时间与消息时间，采纳窗口按 72 小时口径计算；
- 权限双层校验：页面入口按角色出菜单，越权直达也只得到无权限提示页。

## 3 全局界面状态

- 空态：悬赏列表无悬赏时展示引导文案与发布入口；悬赏详情回答页无回答时展示还没有回答来做第一个的引导；消息通知页无消息时展示暂无消息说明；
- 无权限：回答者与平台运营进入我的悬赏得到无权限提示页；平台运营进入消息通知得到无权限提示页，均提供返回列表入口；
- 服务器异常：静态原型以本地数据运行，数据缺失时页面顶部展示异常横幅与重试按钮；
- 重复提交：发布、回答、采纳、下架四类提交按钮点击后立即禁用，动作完成前不可再次触发；
- 内容被删：悬赏单或回答单在渲染前被移除时列表跳过该条，详情页给出已结案或已下架的说明。
