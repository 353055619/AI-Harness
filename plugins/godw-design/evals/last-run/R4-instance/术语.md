# 悬赏厅完整卷 · 术语表

| 术语 | 定义 | 出处 |
| --- | --- | --- |
| 悬赏单 | 楼主发布的悬赏载体，含标题、描述、积分与状态，生命周期为草稿、进行中、已结悬赏、已下架 | 原始需求 §4 FR-01 |
| 回答单 | 回答者针对某张悬赏单提交的回答载体，状态为已提交、已采纳、未采纳 | 原始需求 §4 FR-02 |
| 消息记录 | 系统在关键事件后生成的站内通知载体，状态为未读、已读，类型含新回答、采纳结果、积分到账、下架结果 | 原始需求 §4 FR-04 |
| 采纳 | 楼主在采纳窗口内选定唯一回答并触发结算的动作 | 原始需求 §4 FR-03 |
| 采纳窗口 | 悬赏发布后 72 小时内楼主可执行采纳的时间段 | 原始需求 §4 FR-03 |
| 积分冻结 | 发布悬赏时系统预扣积分，采纳后划给回答者，下架后退回楼主 | 原始需求 §4 FR-01、FR-05 |
| 下架 | 平台运营对违规悬赏执行的下线处置，需填写原因并通知楼主 | 原始需求 §4 FR-05 |
| 未读数 | 当前角色名下状态为未读的消息记录条数，展示在顶栏角标 | 原始需求 §4 FR-04 |
| 触达率 | 目标角色在事件发生后 24 小时内打开消息通知页的比例 | 原始需求 §1 |
